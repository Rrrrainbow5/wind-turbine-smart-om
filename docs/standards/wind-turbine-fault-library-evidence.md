# v0.2 风机传动链故障库与规范证据底稿

## 1. 使用原则

本库用于定义诊断类别、信号证据和可计算公式，不将标准名称误写为算法精度或故障阈值依据。所有具体频率仅在样本已登记转速、齿数或轴承几何参数时计算；否则 UI 只显示公式、变量和“结构参数未提供”。

## 2. 规范范围

| 资料 | 本项目采用范围 | 不作出的声明 |
| --- | --- | --- |
| IEC 61400-25 系列 | 风电场监测/控制通信及信息模型语境，用于 SCADA 数据来源说明 | 不作为齿轮或轴承故障机理标准 |
| ISO 13373 系列 | 振动状态监测、诊断方法和报告语境 | 不提供本项目的固定报警阈值 |
| ISO 13374-1 | 状态监测数据处理、状态检测、健康评估和预后流程语境 | 不等同于某个 AI 模型实现 |
| ISO 13379-1 | 状态监测数据解释与诊断的通用指南 | 不为样本提供未经验证的部件映射 |
| ISO 15243 | 滚动轴承失效模式、术语和损伤分类 | 不凭名称直接确认 CAD 网格或 CARE 事件对应具体轴承 |

## 3. 故障库

| fault_class | 典型失效形式 | 主要机理 | 可观测证据 | 特征频率/关系 | 适用条件 |
| --- | --- | --- | --- | --- | --- |
| GEAR | 点蚀、磨损、裂纹、断齿、偏心 | 啮合刚度周期变化、冲击、侧隙/偏心变化 | 振动边带、包络谱、啮合频率谐波、油液颗粒（若有） | `GMF = Z × fr`；边带 `GMF ± k × fr` | 必须有齿数 `Z` 与轴转频 `fr` |
| BEARING | 内圈、外圈、滚动体、保持架损伤 | 局部缺陷产生周期冲击并激发共振 | 加速度峭度、包络谱、特征频率及谐波 | BPFO/BPFI/BSF/FTF，见第 4 节 | 必须有 `n,d,D,theta,fr`；必要时须有轴承型号和载荷方向 |
| VIBRATION | 不平衡、不对中、机械松动、共振 | 质量偏心、轴系角/平行偏差、连接刚度下降、固有频率激发 | 径向/轴向振动、相位、1X/2X 谐波、宽带冲击 | 不平衡通常关注 `1X=fr`；不对中通常关注 `1X/2X` 与轴向分量；松动常见多次谐波 | 不能以单一谱峰确诊；须结合方向、相位、工况和趋势 |
| ELECTRICAL | 定子匝间短路、转子断条、气隙偏心、电流不平衡 | 磁场不对称、转差扰动、电磁转矩波动 | 三相电流不平衡、MCSA 边带、功率/温度耦合趋势 | 电源频率及与转差 `s` 相关的边带；具体式由电机极对数、供电频率和转差决定 | 必须有电机拓扑、供电频率、极对数和转速；无参数时只展示变量关系 |

## 4. 轴承与齿轮公式

| 名称 | 公式 | 变量与单位 |
| --- | --- | --- |
| 转频 | `fr = rpm / 60` | `rpm`：r/min；`fr`：Hz |
| 齿轮啮合频率（GMF） | `GMF = Z × fr` | `Z`：齿数；`fr`：啮合齿轮所在轴转频 Hz |
| 外圈通过频率（BPFO） | `BPFO = (n / 2) × fr × [1 - (d / D) × cos(theta)]` | `n`：滚动体数；`d`：滚动体直径；`D`：节圆直径；`theta`：接触角 |
| 内圈通过频率（BPFI） | `BPFI = (n / 2) × fr × [1 + (d / D) × cos(theta)]` | 同上 |
| 滚动体自转频率（BSF） | `BSF = (D / 2d) × fr × [1 - ((d / D) × cos(theta))^2]` | 同上 |
| 保持架频率（FTF） | `FTF = (1 / 2) × fr × [1 - (d / D) × cos(theta)]` | 同上 |

> 公式输出单位为 Hz。B/D 必须将计算所用结构参数、转速来源和样本 `sample_id` 一并返回；若任一参数缺失，`feature_frequency_hz` 为 `null` 并提供 `missing_parameters`。

## 5. 对三维高亮的约束

1. API 返回的 `component_key` 必须来自样本或已审核映射表。
2. CARE Event 与 CAD 零件尚未核验时，高亮状态为 `UNVERIFIED`，不得将任意轴承网格标为“真实故障部件”。
3. `component_key` 未映射时仅显示“定位待核验”，不得使用名称模糊匹配随意标红。

## 6. v0.2 首个演示案例

`SIM_WT02_BEARING_OUTER_S70_V02_W001` 是预留的模拟轴承外圈损伤样本，类别为 `BEARING`、故障形式为 `outer-race damage`。在 B/D 提供轴承参数、波形文件、随机种子和 SHA-256 前，状态保持 `PENDING_EVIDENCE`，不得描述为真实采集或 CARE 原始波形。
