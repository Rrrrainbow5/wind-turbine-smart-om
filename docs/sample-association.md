# 样本关联与三维定位

接口模式：选择实验评估记录或上传多通道 JSON → 选择机组 → 选择 CAD 已识别的转子主轴轴承组/传动链轴承组 → 确认关联并三维定位 → 展开维护评估。

部件选项从实际加载的 CAD 分类节点生成，未加载时禁止确认。节点数量不是独立物理轴承数量；内外圈预测均映射到轴承总成。

关联是本次会话的展示关系，不是样本来源证明。更换样本、部件、服务地址、模式或手动选择其他机组会清除三维关联。机组健康指数、遥测、CARE 事件与维护记录不被实验样本覆盖。

实验预测损伤映射为红色，健康样本不添加故障高亮；上传数据尚未推理，仅以黄色指示采集位置。分类分数不转换为现场风险。实验查询是保存的留出评估，不是在线模型推理。

上传数据计算信号统计与变换，但当前没有部署诊断权重，不能输出故障结论。维护评估是证据核对及安全清单，不自动创建或执行工单、不宣称故障修复。
