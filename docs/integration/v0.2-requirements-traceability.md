# v0.2 导师意见验收追溯矩阵

## 核心一致性原则

一个诊断流程只接受一个 `sample_id`。原始波形、预处理结果、统计特征、时频图、模型推理、二维定位、三维 `component_key` 高亮和维护建议必须引用同一 `sample_id`、`data_origin` 和处理版本。

| 导师意见 | 可交付证据 | 数据/API 契约 | 前端验收 | 验收状态 |
| --- | --- | --- | --- | --- |
| 1. 传动链故障库 | `docs/standards/wind-turbine-fault-library-evidence.md` | `GET /api/fault-library` 返回类别、机理、公式、变量、适用条件和来源 | 故障库页按齿轮/轴承/振动/电气分类展示 | A 已建底稿；D/C 待接入 |
| 2. 多通道可视化与处理链 | `signal-source-register.md`、`signal-sample-manifest.csv` | `POST /api/samples`、`POST /api/diagnosis/analyze` 返回状态链和结果引用 | 原始时域 -> 预处理 -> STFT/小波包 -> 频谱 -> 统计特征顺序完整 | 待 B/D/C |
| 3. 混合 AI 诊断 | `literature-evidence-matrix.csv`、B 的 model card | 返回 `model_version`、分支输出、门控权重、置信度/不确定性 | 不把 robust-z 基线称为最终模型 | 文献原文已由 A 核验；B 已有实验结果，但当前分组状态为 `BLOCKED_INSUFFICIENT_BEARINGS`，后端 `hybrid-ai-v0.2.0` 仍为 `NOT_IMPLEMENTED` |
| 4. 图表规范与 t-SNE | 样本清单的通道/单位/采样率 | 返回图表标题、轴单位、色标、特征版本、随机种子 | 图例、坐标、单位、缩放、提示和当前样本标记齐全 | 待 C |
| 5. 交互与物理耦合 | `SIM_V02_COUPLED` 条目 | `POST /api/demo/simulate` 返回同一 `sample_id` 下全部耦合量 | 滑块仅在演示弹窗；真实录入支持数组/CSV；故障联动参数变化 | 待 B/D/C |

## 诊断状态机验收

`UPLOADED -> VALIDATED -> PREPROCESSED -> TRANSFORMED -> INFERRED`

任何失败必须终止在对应状态并返回可追踪错误，禁止上传后直接伪装为已完成诊断。
