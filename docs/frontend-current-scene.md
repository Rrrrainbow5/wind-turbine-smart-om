# 当前前端场景说明

## 当前版本

当前 `main` 工作树对应海上风场无人机巡检版，不是此前的陆上山地演示版。场景使用 DaySky HDRI 作为天空与环境光，程序化动态海面作为水面，8 台风机沿离岸阵列布置。

每台风机包含：

- 工程 GLB 外形和 CAD 节点：`frontend/public/assets/wind-turbine-engineering.glb`
- 海上单桩基础和黄色防撞过渡段
- 状态指示灯及 Event 51 风险状态
- 可点击的机组根节点

## 无人机操作

- 默认视角位于当前选中机组机舱附近，模拟约 45 m 安全巡检距离。
- `1` 巡检：机舱斜侧视角。
- `2` 叶轮：叶轮正面视角。
- `3` 机舱：机舱侧面视角。
- `4` 全场：海上风场航拍视角。
- 选择其他机组或切换预设视角时，镜头使用缓入缓出飞行过渡，不瞬移。
- 再次点击已选机组的机舱，或打开“工程剖切视图”，可透明显示机舱外壳并查看内部零件。

## 数据边界

演示模式的状态数值仍标记为 `SIMULATED`。接口模式下，风机状态、风险、维护方案和复测结果均从 D 后端读取；后端没有数据时前端显示空状态，不补造数值。`WT02_COMPONENT_01` 与 Event 51 的具体物理部件映射仍保持 `UNVERIFIED`，工程模型中的轴承名称不等同于 CARE 官方映射。
