# CARE 跨风机模型优化与验收协议

日期：2026-11-02

对象：CARE Wind Farm A 十分钟聚合 SCADA 六分类模型
现有基线：`care-scada-rf-v1`，按物理风机整体留出 Accuracy 46.83%，Macro F1 12.65%

## 1. 优化目标

本轮不是隐藏或改写 12.65%，而是在不降低验证强度的前提下实际优化模型。所有候选模型继续按原始物理风机 `asset_id` 整体留出，训练和测试不得共享同一风机、事件切片或重叠时间窗口。

优化目标按优先级排列：

1. 提高跨风机留出 Macro F1，并降低不同留出风机之间的波动。
2. 提高故障类而非仅正常类的召回率，避免 Accuracy 被正常样本主导。
3. 对训练折缺少目标类别、证据不足或类别分数接近的样本允许拒识，不强制给出错误故障名称。
4. 保留可复现的数据来源、划分、特征、模型、随机种子和完整评估产物。

不得通过随机窗口划分、让同一风机同时出现在训练和测试、挑选容易案例或删除失败折来提高页面数字。

## 2. 数据边界与分组规则

- 数据源限定为已登记的 CARE Version 6 Wind Farm A 十分钟聚合 SCADA；不得称为高频振动或电流波形。
- 样本单元仍为同一物理风机的连续 36 条十分钟记录，即六小时窗口。
- 外层评估使用 Leave-One-Asset-Out：每折完整留出一台物理风机。
- 同一事件的重叠窗口只允许位于同一折；不得将相邻窗口拆到训练和测试两侧。
- 缺失值填补、归一化、特征筛选、阈值和超参数只能在每个外层训练折中拟合。
- 若需要调参，在外层训练折内部再按物理风机或事件分组验证；禁止使用外层测试风机选参。
- 记录每一类的窗口数、物理风机数和事件数。只有一个独立物理风机的类别不能宣称已验证跨风机识别能力。

## 3. 候选优化路线

### 3.1 特征

在现有每通道中位数、标准差、首尾变化基础上，逐项消融比较：

- 10%、25%、75%、90% 分位数与四分位距；
- 最小值、最大值、稳健极差；
- Theil-Sen 或普通最小二乘趋势斜率；
- 一阶差分中位数、差分 MAD、方向变化次数；
- 缺失率、有效点数与最长连续缺失长度；
- 在训练折内拟合的风机/工况稳健归一化特征；
- 功率、风速、转速等运行工况的相对偏差和受控交互项。

风机编号、事件编号、绝对日期、标签编码及任何可直接识别来源风机的字段不得进入模型。

### 3.2 类别与事件不平衡

- 保留类别权重与事件权重，报告每个窗口最终权重分布。
- 比较 class-balanced、effective-number 与现有“类内事件等权”方案。
- 不在划分前执行过采样；若训练折内部过采样，必须按事件成组并只作用于训练折。
- 单风机类别在对应留出折中属于 open-set 情形，应标记 `UNSEEN_CLASS_IN_TRAIN`，不能把该折失败当成普通参数误差。

### 3.3 模型

至少比较：

1. 加权 Random Forest（现有可复现基线）；
2. Extra Trees；
3. HistGradientBoosting 或可复现的 XGBoost；
4. 两阶段模型：正常/异常，再对可支持的故障大类分类。

模型选择以外层严格留出结果为准。若六分类受单风机类别限制无法稳定泛化，应保留六分类训练案例回放，同时将跨风机生产输出降级为有数据支持的系统大类或“异常待复核”，不能伪造六分类能力。

## 4. 拒识与人工复核

候选模型需要在内层验证中确定拒识规则，至少考虑：

- 最高类别分数低于阈值；
- 第一、第二类别分数差低于阈值；
- 测试样本超出训练折稳健特征分布；
- 预测类别在训练折中不存在；
- 关键通道缺失率超过上限。

拒识输出统一为 `LOW_CONFIDENCE_REVIEW_REQUIRED`，页面展示“证据不足，建议人工复核”，不得用最接近类别强行替代。拒识阈值只能在训练折内部确定。

## 5. 必须输出的评估产物

每个候选配置至少生成：

- 总体 Macro F1、Balanced Accuracy、MCC 和 Accuracy；
- 每类 Precision、Recall、F1、Support；
- 每台留出风机的 Macro F1、Balanced Accuracy、拒识率；
- 聚合混淆矩阵和逐风机混淆矩阵；
- 有拒识与无拒识两组指标，以及覆盖率-性能曲线；
- 每折训练类别、测试类别和 `missing_train_classes`；
- 特征消融、模型配置、随机种子、scikit-learn/XGBoost 版本；
- 数据源哈希、特征缓存哈希、模型哈希；
- 本次样本最终模型预测与对应严格留出预测，二者不可混写。

所有数值写入机器可读 `report.json`；网页只能读取该报告，不允许手填更高分数。

## 6. 新模型替换旧模型的门槛

新模型只有同时满足以下条件，才可以替换网页现有跨风机评估：

1. 使用与基线相同或更严格的外层 Leave-One-Asset-Out 协议；
2. 聚合 Macro F1 明确高于 0.1265，且提升不是来自删除困难类别或困难风机；
3. 至少两个有多风机支持的类别 F1 得到提升，不能仅提高正常类；
4. 报告所有外层折，无失败折、零分折或缺类折隐匿；
5. 数据、代码、配置、随机种子和产物哈希可复现；
6. 前端展示的模型版本、分类分数、评估报告与实际导出模型一致；
7. 完成自动测试，确认便携推理与训练环境预测一致。

不预设虚假的目标分数。如果模型虽有提升但仍不足以支持新风机六分类，页面必须保留“实验验证/辅助判断”边界，并启用拒识或降低输出粒度。

## 7. 前端字段契约

信号诊断页将“本次样本预测”和“跨风机模型验证”分开。建议评估对象至少提供：

```json
{
  "model_version": "care-scada-optimized-v2",
  "validation_protocol": "leave-one-physical-asset-out",
  "macro_f1": 0.0,
  "balanced_accuracy": 0.0,
  "coverage": 0.0,
  "rejection_rate": 0.0,
  "per_class": {},
  "per_asset": [],
  "confusion_labels": [],
  "confusion_matrix": [],
  "limits": []
}
```

单样本对象分开提供：

- `true_label`：数据集事件标签，不称现场拆检结论；
- `final_prediction`：用全部训练数据拟合的案例回放结果；
- `held_out_prediction`：该物理风机未参与训练时的预测；
- `held_out_status`：`PREDICTED`、`REJECTED` 或 `UNSEEN_CLASS_IN_TRAIN`；
- `class_scores`：未校准时称分类分数，不称故障概率；
- `sample_id`、`source_asset`、`model_version`、`data_origin`。

## 8. 页面允许与禁止的表述

允许：

- “CARE 历史标注窗口分类实验”；
- “按物理风机整体留出验证”；
- “本次留出预测与事件标签一致/不一致”；
- “分类分数未校准，低置信度样本进入人工复核”。

禁止：

- 将训练案例回放正确说成独立测试正确；
- 将类别分数称为现场故障概率；
- 将 Macro F1 解释为单样本答对概率；
- 将 CARE 聚合 SCADA 称为高频原始波形；
- 在训练折缺少目标类时声称模型已验证该类跨风机泛化；
- 为答辩展示手工修改指标或隐藏错误预测。

## 9. 回归验收

1. 同一配置连续运行两次，指标、预测和哈希一致。
2. 自动断言任一外层折训练与测试的 `asset_id` 交集为空。
3. 自动断言预处理器和特征筛选器只在训练折拟合。
4. 对每个类别列出独立风机数；单风机类别显示验证限制。
5. 齿轮箱故障误判液压系统的案例进入错误分析，记录主导特征、训练支持和分数差。
6. 前端展示值逐项与 `report.json` 对照，模型版本和哈希一致。
7. 若新模型未通过替换门槛，旧模型不被静默替换；页面继续诚实展示当前结果与限制。
