# SCADA 三分支试验 v1

本实验独立新增，不替换网页、接口或已有随机森林。适用输入是 CARE A 风场十分钟聚合数据，不是原始振动，也不是 STFT 时频图。仅供研究，不能据此宣称已完成工程部署或覆盖全部部件故障。

## 结构

每个样本包含连续 36 条十分钟记录，即约六小时，40 个固定通道。固定使用全部通道，不根据事件标签选择输入通道。

1. 统计分支：各通道中位数、标准差、末值减首值，共 120 个特征，输入 XGBoost（100 棵树、深度 3）。
2. 趋势分支：36×40 的数据输入两层一维卷积，各 24 通道，核宽 3，全局平均池化后分类。
3. 关系分支：各通道在窗口内的两两相关性，共 780 个数，输入 32 隐藏单元的神经网络。恒定通道的相关性记零。

门控网络根据三路类别分数计算三个权重，做加权融合。它与原规划的“工程特征＋原始振动＋STFT”结构不同，应称为“SCADA 多视图三分支融合试验”。神经分支固定训练 25 轮，未依据外层测试集调参。

## 数据与验证

沿用已有 CARE 提取规则：只取明确事件区间；排除 train 标记行与冲突标签时间段；按不重叠六小时分组；要求 36 个连续时间戳、每通道至少 80% 非缺失。排除变压器类后，保留 909 个窗口、5 台风机、5 类状态。

| 类别 | 窗口数 | 独立风机编号 |
|---|---:|---|
| 齿轮箱 | 25 | 10 |
| 齿轮箱轴承 | 16 | 21 |
| 发电机轴承 | 170 | 0、10 |
| 正常 | 543 | 0、10、11、13、21 |
| 液压系统 | 155 | 0、10、13、21 |

外层每次留出整台风机测试，五折后汇总所有测试预测计算 Macro F1（不是五折 F1 的简单平均）。外层训练集中再按风机留出产生三路预测，供门控训练，避免门控看到分支的训练集预测。缺失值填补与标准化均只拟合当前训练部分。训练权重平衡类别及类别内事件。

齿轮箱与齿轮箱轴承类各仅出现于一台风机。对应风机留出后，该类在训练集中不存在，因此不能学会识别该类。所有分支对未见类别统一输出零概率；仍保留这些样本计入外层评价。内层此类不可能正确的样本从门控拟合中排除，并在报告中记录数量。这使得门控训练也受类别覆盖不足影响。

事件区间标签来自数据集事件元数据，不等于逐窗口经过专家确认的故障起点。禁止把资产编号、事件编号、日期或标签作为模型输入。

## 首轮结果

| 方法 | 汇总 Macro F1 |
|---|---:|
| 统计特征 XGBoost | 18.22% |
| 趋势一维卷积 | 13.73% |
| 通道关系网络 | 16.01% |
| 三路等权平均 | 15.64% |
| 三路门控融合 | 16.59% |
| 同划分随机森林 | 15.47% |

三分支门控比本次随机森林高约 1.12 个百分点，但低于单独 XGBoost。未做多随机种子和统计显著性检验，不能据此宣称稳定提升。总体表现仍低，不满足可靠自动诊断要求。这里是五类实验，不能直接与此前六类的 12.6% 比较。

优先补充同一故障在多台独立机组上的带标签数据，其次才是比较窗口长度、分支结构和融合方式。不能通过随机拆分相邻窗口来获得看似更好的成绩。

## 运行与产物

从仓库根目录运行：

```powershell
python -m ai.care_scada_three_branch --farm 'D:\AAA\工创\工创\CARE_To_Compare_v6\CARE_To_Compare\Wind Farm A' --output artifacts/ai/scada-three-branch-v1 --epochs 25
```

依赖：numpy、pandas、scipy、scikit-learn、torch、xgboost；测试另需 pytest。实际版本记录在 report.json 中。

- `artifacts/ai/scada-three-branch-v1/report.json`：数据文件哈希、类别覆盖、每折结果、混淆矩阵、每样本预测、损失曲线、软件版本。
- 各 `asset-*` 目录：对应外层训练集拟合的三个分支、预处理器、门控权重。
- `all-data-research/`：完成独立评估后用全部样本拟合的研究权重；门控使用按风机留出的预测训练。此模型没有新的独立测试成绩，不得用全部数据再测一次作为效果证明。
- `windows-cache.json`：可核验原文件哈希的提取缓存。

大文件与原始数据保留本地，遵循仓库既有忽略规则。joblib 预处理文件仅加载本机可信训练产物，不能接受外部上传的同类文件。

已有四项检查通过：相关性对尺度/偏置的稳定性与恒定通道处理、类别/事件权重平衡、门控概率归一化及不可能类别计数、卷积权重保存/恢复一致性。

## 继续验证：三次初始化与扩充数据核查

保持相同机组划分、25 轮训练和结构，使用种子 20261105、20261106、20261107。没有从中选择最好种子作为正式结果。随机森林保持原基线固定种子，作为一致参照。

| 方法 | 三次 Macro F1（%） | 均值 ± 总体标准差（百分点） |
|---|---|---|
| XGBoost | 18.22 / 18.15 / 18.71 | 18.36 ± 0.25 |
| 趋势 CNN | 13.73 / 14.69 / 14.58 | 14.33 ± 0.43 |
| 关系网络 | 16.01 / 14.99 / 15.02 | 15.34 ± 0.47 |
| 等权融合 | 15.64 / 15.96 / 15.86 | 15.82 ± 0.13 |
| 门控融合 | 16.59 / 17.89 / 15.15 | 16.54 ± 1.12 |
| 固定随机森林参照 | 15.47 / 15.47 / 15.47 | 15.47 |

这仅衡量初始化变化，不是独立测试数据集重复抽样，不是置信区间。门控在一个种子下还低于随机森林，三次均低于 XGBoost；没有证据宣称融合带来稳定增益。应保留研究权重，不替换现有推理入口。

B 风场元数据包含 15 个事件、9 台独立机组，其中 3 个轴承异常事件分别描述转子/主轴承问题，另有 3 个变压器温度异常事件。不能将这些标签直接改成 A 场的齿轮箱轴承故障。C 风场包含 58 个事件、22 台机组，31 个正常事件；故障说明涉及变桨、液压、通信、电气和多故障混合，部分根因明确标为未知。其 sensor_0 是电流，而 A 场 sensor_0 是环境温度，编号同名不代表同一测量。

因此本轮不直接拼接 B/C 来抬高五分类成绩。后续扩展必须建立经核验的语义通道映射及事件标签表；若改为正常/异常或宽类别任务，须另立实验报告，不与本五分类指标直接比较。完整实验报告分别保存在 `artifacts/ai/scada-three-branch-seed-20261106/` 和 `artifacts/ai/scada-three-branch-seed-20261107/`。
